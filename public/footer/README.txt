The small looping animation shown directly on the page at the bottom of every screen except the main menu.

    animation.mp4

The clip is a character in the bottom-right corner of a solid black frame. The app crops each frame to that
corner and cuts away the black that touches the outside of the picture, so the character appears straight on the
screen. Black enclosed inside the character (its dark hair) is kept.

If you replace the clip with one where the character sits somewhere else, tell Claude (the crop is CROP_X and CROP_Y
in src/FooterAnimation.jsx). Cut-out tuning is BLACK_MAX in src/silhouetteKey.js.

If the file is missing, nothing is shown.

This file only keeps the folder in git. You can delete it.
